# Me, Inc. 個人營運帳本 v2

> 把自己當成一間公司經營。資料存在你自己的 Google Sheet，前端放 GitHub Pages。

## v2 改了什麼

| 項目 | v1 | v2 |
|---|---|---|
| 前端載入量 | 約 3.5 MB（Tailwind CDN + React + Babel + 中文網頁字型） | 約 72 KB，全部自家託管 |
| 開啟流程 | 等 CDN 下載 → 瀏覽器即時編譯 JSX → 等 API 回應才顯示 | 直接顯示快取資料，背景更新 |
| 期間 | 以「月」命名，7/5–8/4 會標成 8 月 | 直接顯示區間 `7/5–8/4`，與結算日同步 |
| 結算日 | 只存在手機瀏覽器，清快取就變回 1 號 | 存在 Google Sheet，換手機不會遺失 |
| 重複記錄 | 連點或重送會產生第二筆 | 前端擋連點、後端冪等 + 上鎖，另有清理工具 |

## 檔案

| 檔案 | 用途 | 是否需上傳 GitHub |
|---|---|---|
| `index.html` | 外殼與樣式 | ✅ |
| `app.js` | 主程式 | ✅ |
| `vendor.js` | Preact + htm（14 KB，自家託管） | ✅ **不可漏** |
| `sw.js` | 離線快取（v6） | ✅ |
| `manifest.json`、`icons/` | PWA 圖示設定 | ✅ |
| `google-apps-script.gs` | 後端（貼到 Apps Script，不必上傳） | ❌ |

## 更新步驟

1. **先更新後端**：Google Sheet → 擴充功能 → Apps Script → 全選刪除 → 貼上新版 `google-apps-script.gs` → 儲存 → 部署 → 管理部署作業 → 鉛筆 → 版本選「新版本」→ 部署。網址不變，前端不用重設。
2. **再更新前端**：把 `index.html`、`app.js`、`vendor.js`、`sw.js` 推上 GitHub（覆蓋舊檔）。
3. 手機開啟網址後**重新整理兩次**。第一次是讓新的 Service Worker（v7）安裝並汰換舊快取，第二次才會載入新版畫面。之後每次開啟都會自動取得最新版。
4. 進「設定 → 結算週期」確認結算日（例如 5 號），按套用。此設定會寫入 Sheet 的 `Settings` 工作表。

> 首次載入新版時，Sheet 會自動新增 `Settings` 的 `cycleDay` 欄位，原有交易資料完全不動。

## 重複記錄的防線

1. 表單送出後按鈕立即鎖定，連點無效。
2. 後端 `LockService` 讓寫入排隊，避免併發。
3. `addTxn` 冪等：同一 `id` 重送不會新增；內容相同且建立時間相差 60 秒內，視為同一筆。
4. `updateTxn` / `deleteTxn` 找不到 id 時回成功，避免離線佇列卡住無限重試。
5. 設定內「掃描並清除重複記錄」：只刪除 `id` 完全相同的多餘列；同日同額但 id 不同者僅回報數量，交由你人工判斷。

## 後端速度（v3）

| 手段 | 省下的時間 |
|---|---|
| CacheService 快取整包 JSON，6 小時有效 | 命中時試算表 RPC 由 3 次降為 0 次，約 0.5–2 秒 |
| 移除每列一次的 `Utilities.formatDate`，改本機運算 | 資料愈多省愈多 |
| 只讀實際使用範圍，不重複開工作表 | 數百毫秒 |
| `installKeepWarm()` 每 5 分鐘預熱 | 大幅降低 2–6 秒的冷啟動機率 |
| `index.html` 在載入程式的同時就發出請求 | 約 100–300 毫秒 |

任何寫入都會立即清除快取，資料不會過期。剩下無法消除的是 Google 端的冷啟動與 `/exec` 的兩段轉址。

**安裝預熱（只需做一次）**：Apps Script 編輯器上方函式清單選 `installKeepWarm` → 執行 → 授權。之後每 5 分鐘會自動呼叫一次，讓容器保持溫熱。此觸發器每天約執行 288 次，遠低於 Apps Script 的每日配額。

## 開啟速度

- 首屏不等後台：程式一載入就直接畫出畫面，Google Sheet 的資料在背景同步，上方會顯示「正在連線後台⋯」。
- 後台 12 秒沒回應就轉為「連線失敗」並提供重試鍵，不會停在轉圈畫面。
- 有快取時直接顯示上次資料，再以最新資料覆蓋。
- Apps Script 首次呼叫本身有 3–8 秒冷啟動，這段時間屬正常，但已不影響畫面可用性。

## 期間規則

結算日 `n`（1–28）決定一期的起訖：

- `n = 5` → `7/5–8/4`、`8/5–9/4`⋯，畫面一律顯示區間，不再顯示月份。
- `n = 1` → 自然月。
- 日期比對只取 `yyyy-MM-dd`，不經時區換算，4 日與 5 日交界不會跑掉。

## 隱私

- 資料只存在你的 Google Sheet。
- API 網址等同密鑰，不要公開。目前部署存取權為「所有人」，任何人取得網址即可讀寫；若要再收緊，可在後端加上權杖驗證。
